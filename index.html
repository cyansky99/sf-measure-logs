sf-measure-logs

sf-measure-logs is a personal research utility used to upload experimental measurement logs and data files to Google Drive.

The application uses the Google Drive API through rclone. It is used to transfer measurement data generated on research computers to the owner's Google Drive for storage and analysis.

Google Drive access is used only for files created or managed by this application. Google user data is not sold, shared, or used for advertising.

This application is intended for personal research use and is not offered as a public service.
